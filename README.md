# CareerPilot

**AI-Powered Career Development, Resume Optimization and Placement Intelligence Platform**

CareerPilot is a web-based career support platform designed to help students manage career profiles, build resumes, explore job opportunities, track applications, and discover career paths based on their skills. It also includes a machine-learning-based career prediction component.

## Features

- **User authentication:** registration and login for student and administrator roles.
- **Student profiles:** store profile details and skills.
- **Resume builder:** generate a downloadable resume.
- **Job exploration:** browse and search jobs by keywords and location.
- **Skill compatibility analysis:** compare student skills with a job's required skills and show matched skills, missing skills, and a compatibility percentage.
- **Career recommendations:** recommend career paths based on student skills.
- **ML-based career prediction:** use a trained scikit-learn model to predict a career category from profile skills.
- **Job applications:** submit applications and view application status.
- **Notifications:** notify students about application-status changes.
- **Administrator dashboard:** manage job listings and review applications.

> **Model limitation:** The career prediction model was trained using a small, manually prepared dataset. Treat predictions as a prototype, not validated career guidance.

## Technology Stack

- **Backend:** Python, Flask
- **Database:** SQLite
- **Authentication:** Flask-Login
- **Frontend:** HTML, CSS, Bootstrap, Jinja templates
- **Machine learning:** scikit-learn, pandas, joblib
- **Resume/document processing:** ReportLab, PyMuPDF (`fitz`), Pillow

## Setup

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd CareerPilot
```

Replace `<YOUR_REPOSITORY_URL>` with your repository URL.

### 2. Create and activate a virtual environment

**Windows (PowerShell):**

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use Command Prompt:

```bat
py -m venv .venv
.venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

If `requirements.txt` exists:

```bash
pip install -r requirements.txt
```

If you have not created it yet, install the packages used by the application:

```bash
pip install Flask Flask-Login scikit-learn pandas joblib reportlab pymupdf Pillow
```

Then create/update the dependency list:

```bash
pip freeze > requirements.txt
```

Review `requirements.txt` before committing it to ensure it contains the intended dependencies.

### 4. Configure secrets

Use a secure Flask secret key supplied through an environment variable, and make sure `app.py` reads it from the environment. Do not publish production credentials, API keys, or private configuration values.

### 5. Prepare the machine-learning model

If `career_model.joblib` is not included in the repository, train it from the training dataset:

```bash
python train_career_model.py
```

The script should generate `career_model.joblib`. Check that the model-loading path in `app.py` matches the file's location.

### 6. Run the application

```bash
python app.py
```

Open the local URL printed by Flask, commonly:

```text
http://127.0.0.1:5000/
```

Register an account, or use an administrator account only if you have configured one. Do not publish default or real credentials in this README.

## Machine-Learning Notes

The career prediction component uses a text-based feature pipeline with TF-IDF features and Logistic Regression. The training examples are manually prepared and limited in size.

- Predictions depend on the coverage and quality of the training data.
- A displayed probability is a model estimate, not a guarantee of career suitability.
- Evaluate the model on larger, representative data before using it for consequential decisions.
- Avoid entering sensitive personal information into a public deployment without appropriate privacy and security measures.

The job compatibility percentage is calculated from the overlap between normalized student skills and a job's listed required skills. It is different from the machine-learning career prediction.

## Database

## Limitations

- Career recommendations and compatibility results depend on the skills entered and the job descriptions stored in the database.
- The manually prepared ML dataset is small and does not establish real-world prediction accuracy.
- Job listings and placement information depend on data entered into the system; the application does not inherently guarantee live job feeds or placements.
